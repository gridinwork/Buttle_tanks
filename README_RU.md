# Buttle_tanks — Tank Battle Solo Test v0.2

Первая опубликованная версия проекта танчиков для Windows/Python в стиле классических 8-битных игр.

## Версия

**v0.2 — первая версия проекта в GitHub.**

По умолчанию запускается режим **одного игрока с прохождением уровней**.

### Что уже реализовано

- одиночное прохождение 12 уровней;
- противники с ИИ и постепенным появлением;
- очки и жизни игрока;
- база, которую необходимо защищать;
- разрушаемые кирпичные стены;
- сталь, вода, лес и лёд;
- звуки выстрелов, попаданий, взрывов, начала уровня и Game Over;
- автоматический переход на следующий уровень;
- полноэкранный режим;
- дополнительный запуск кооперативного режима;
- экспериментальные AI/API-модули.

## Управление

- **Стрелки** — движение
- **Пробел** или **Enter** — огонь
- **F11** — полноэкранный режим
- **Esc** — пауза и меню
- **R** — начать заново после Game Over

## Запуск в Windows

Запустите:

```bat
start.bat
```

При необходимости скрипт установит `pygame-ce`, после чего запустит игру.

Ручной запуск:

```bash
pip install -r requirements.txt
python game.py
```

## Сборка EXE

Для сборки Windows-версии используется:

```bat
build_exe.bat
```

## Графика и звук

Графика берётся из `Dump.nes`, если файл находится рядом с `game.py`. При его отсутствии используются встроенные спрайты.

Звуковые файлы находятся в папке `audio/`.
