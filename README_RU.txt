TANK BATTLE DUO — TEST BUILD 0.2

Режим по умолчанию: ОДИН ИГРОК, прохождение уровней.

Управление игроком 1:
Стрелки — движение
Пробел — огонь (Enter тоже)
F11 — полноэкранный режим
R — начать заново после Game Over
Esc — пауза и меню (продолжить, заново, полный экран, выход)

В тестовой версии доступны:
- одиночное прохождение всех 12 уровней;
- враги с ИИ и постепенным появлением;
- очки и жизни;
- база, которую нужно защищать;
- кирпичные разрушаемые стены;
- сталь, вода, лес и лёд;
- звуки выстрелов, попаданий и начала уровня;
- автоматический переход на следующий уровень;
- полноэкранный режим.

start.bat установит pygame при необходимости и запустит игру.
build_exe.bat собирает Windows EXE через PyInstaller.

Графика берётся из Dump.nes (лежит рядом с game.py), если файла нет, используются встроенные спрайты.

Звуки: папка audio (записаны из Dump.nes через extract_audio.py).
